# Route Atelier: маршрут и КП с ИИ

MVP для кейса «Золотое кольцо» (вариант Б: валидатор маршрута и генератор КП).
Менеджер задаёт параметры группы, система собирает два варианта маршрута из проверенной базы и отсеивает переезды дольше 4 часов. Затем локальный Claude пишет коммерческое предложение, а сервис собирает из него готовую HTML-страницу.

## Как запустить

1. Дважды кликните `start.command`. Откроется http://localhost:8765.
2. Если macOS не даёт запустить файл, выполните в Терминале:

   ```bash
   cd ~/Desktop/everday/route-atelier-kp && python3 server.py
   ```

Нужны Python 3.9+ и Claude Code (`claude`) с выполненным входом. Других зависимостей нет.

## Как пользоваться

1. Блок 01: тип тура (короткий на 3 дня или полный на 7–9 дней), направленность (жизнь, еда, культура), группа, темп, бюджет, курс юаня и города. Курс юаня по умолчанию берётся из ЦБ РФ.
2. Блок 02: «Собрать маршрут». Возле каждого города виден его персонаж-хозяин.
3. Блок 03: язык КП (RU, 中文, EN, العربية), аудитория, особые пожелания и персонаж-рассказчик. Нажмите «Сгенерировать КП».
4. Через 1–3 минуты справа появится КП. Его можно открыть, скачать одним HTML-файлом (картинки встроены) или скопировать ссылку.
5. Блок 04: промты для ручной работы с любым ИИ и выгрузка в MD.

Интерфейс переключается на русский, китайский или английский. Ссылка `?lang=zh` или `?lang=en` сразу открывает нужный язык.

В режиме «Авто» рассказчик зависит от направленности тура: жизнь — Медведь, еда — Садко, культура — Алёша Попович. Если в пожеланиях есть явная тема (СПА, ремёсла, зима), она важнее.

Все КП сохраняются в папку `generated/`. Рядом лежит `.json` с текстами ИИ и промтом для разбора.

## Как устроено

- `index.html`: интерфейс MVP с встроенными базами объектов (229) и транспорта (86).
- `server.py`: локальный сервер. Вызывает `claude -p --model opus --effort medium` без инструментов и с JSON-схемой ответа.
- ИИ пишет только тексты: оффер, программу по дням, реплики персонажей, сравнение вариантов, условия. Цены, время в пути, расписания, расчёт стоимости и фото страница берёт из базы. Так ИИ не может исказить цифры.
- Сказочный голос есть только в приветствии рассказчика и в коротких репликах хозяев городов. Остальное КП написано деловым языком.
- Если пожелание клиента невыполнимо по базе, ИИ не обещает его, а предлагает альтернативу в блоке «Честные альтернативы».

## Доступ для других: GitHub Pages и этот Mac как ИИ-сервер

Интерфейс лежит на GitHub Pages. Маршруты собираются прямо в браузере. Для генерации КП страница обращается к ИИ-серверу на Mac владельца через туннель Cloudflare.

1. На Mac владельца дважды кликните `start-public.command`. Скрипт:
   - запускает `server.py` с ключом доступа (ключ лежит в `.access-key`, в git не попадает);
   - поднимает бесплатный туннель `cloudflared` с адресом вида `https://….trycloudflare.com`;
   - записывает этот адрес в `config.json` и пушит его, чтобы Pages узнал новый адрес;
   - не даёт Mac уснуть, пока окно открыто;
   - печатает ссылку для команды: `https://<логин>.github.io/<репозиторий>/?key=<ключ>`.
2. Отправьте эту ссылку команде. Ключ из ссылки запоминается в браузере, а из адресной строки исчезает.
3. Чтобы закрыть доступ, нажмите Ctrl-C в окне скрипта.

Ограничения:

- КП генерируются, только пока Mac включён и скрипт работает. Без сервера на Pages работает сборка маршрутов.
- Адрес туннеля меняется при каждом запуске. Скрипт сам пушит новый адрес, и Pages обновляется за 1–2 минуты.
- Генерации идут по одной, остальные ждут в очереди.
- Все генерации тратят лимиты подписки Claude владельца. Раздавайте ключ только своей команде.
- Наружу сервер отдаёт только `index.html`, `characters.json`, `config.json`, `assets/`, `examples/` и `generated/`. Код, `.git` и ключ закрыты.

Готовое КП открывается по прямой ссылке без ключа: имя файла содержит случайную часть, поэтому его нельзя угадать.

## Примеры

В `examples/` лежат три готовых КП: на русском (Садко), китайском (Садко) и арабском (Афанасий Никитин).

## Настройки

Переменные окружения для `server.py`: `PORT` (8765), `KP_MODEL` (opus), `KP_EFFORT` (medium), `KP_TIMEOUT` (600 с), `ACCESS_KEY` (пусто — без ключа), `ALLOWED_ORIGIN` (`*`), `KP_PARALLEL` (1).
